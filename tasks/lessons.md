# Lessons

Patterns to avoid repeating (CLAUDE.md "Self-Improvement Loop").

## 2026-11-01 audit
- Regexes that read user text: never put two `\s*` around an optional token (`\s*:?\s*`). It backtracks
  polynomially on long whitespace runs. Use possessive `\s*+` (Python 3.11+) or drop optional,
  uncaptured prefixes. Add a timing test with a 10,000-char hostile input for every new pattern.
- Bound the work, not just the input: a 5,000-row cap still cost ~28 s because the model ran once per
  row. Batch model calls (`predict_many`) and time the documented maximum in a test.
- An in-sample score (receipts generated by the same code the parser targets) is a regression check.
  Say so wherever the number appears.
- Look at the real UI at 390 px, not just the tests: the forecast was correct but 6,500 px down.
